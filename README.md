# 📋 منشی من — دستیار هوشمند کارهای روزانه

یک برنامهٔ موبایل (PWA) فارسی که مثل یک منشی باتجربه کارهای روزانه‌تان را **ثبت، دسته‌بندی، تحلیل و یادآوری** می‌کند.
روی اندروید و آیفون کار می‌کند، بدون نیاز به اینترنت (بعد از اولین بار) و بدون سرور. همهٔ اطلاعات فقط روی گوشی خودتان می‌ماند.

## نسخهٔ اندروید (APK) — پیشنهادی

نسخهٔ اندروید همان برنامه است به‌علاوهٔ:
- **یادآوری مطمئن حتی وقتی برنامه بسته است** (اعلان‌های سیستمی زمان‌بندی‌شده که بعد از خاموش/روشن شدن گوشی هم حفظ می‌شوند)
- **ارسال خودکار پیامک** به افرادی که انتخاب می‌کنید، سر زمان یادآوری کار (هزینهٔ پیامک طبق تعرفهٔ اپراتور خودتان)
- اعلان وضعیت ارسال پیامک (ارسال شد / ناموفق) و نمایش آن کنار هر کار

### دریافت APK
با هر push، گیت‌هاب (Actions ← «Android APK») فایل `monshi.apk` را می‌سازد و در بخش **Releases** مخزن می‌گذارد.
آن را روی گوشی دانلود کنید، نصب از منابع ناشناس را مجاز کنید و نصب کنید.
در اولین اجرا اجازهٔ **اعلان‌ها** و هنگام افزودن مخاطب اجازهٔ **ارسال پیامک** را بدهید.

### کلید امضا (اختیاری ولی توصیه‌شده)
بدون تنظیم، APK با یک کلید دیباگ که بین ساخت‌ها ثابت نگه داشته می‌شود امضا می‌شود.
برای کلید اختصاصی و دائمی، یک‌بار روی کامپیوتر بسازید:
```bash
keytool -genkeypair -keystore monshi-release.jks -storetype PKCS12 -alias monshi -keyalg RSA -keysize 2048 -validity 10000
base64 -w0 monshi-release.jks   # خروجی را کپی کنید
```
و در گیت‌هاب (Settings ← Secrets and variables ← Actions) دو secret بسازید:
`MONSHI_KEYSTORE_BASE64` (خروجی base64) و `MONSHI_KEYSTORE_PASSWORD` (رمز کلید).
فایل کلید را جای امنی نگه دارید و هرگز در مخزن قرار ندهید. توجه: با تغییر کلید، یک‌بار باید برنامه را حذف و دوباره نصب کنید (قبلش پشتیبان بگیرید).

### ساخت دستی (نیاز به Android SDK و JDK 21)
```bash
npm ci
npm run android:apk   # خروجی: android/app/build/outputs/apk/release/app-release.apk
```

## نصب نسخهٔ وب روی گوشی

۱. برنامه باید روی یک آدرس `https` باشد. ساده‌ترین راه **GitHub Pages** است:
   در گیت‌هاب: `Settings → Pages → Build and deployment → Deploy from a branch` و شاخهٔ برنامه و پوشهٔ `/ (root)` را انتخاب کنید.
   آدرس برنامه چیزی شبیه `https://<نام‌کاربری>.github.io/Qee/` خواهد شد.
۲. آدرس را روی گوشی باز کنید:
   - **اندروید (Chrome):** منو ⋮ ← «Add to Home screen / نصب برنامه»
   - **آیفون (Safari):** دکمهٔ اشتراک‌گذاری ← «Add to Home Screen» (اعلان‌ها در iOS 16.4 به بعد و فقط پس از افزودن به صفحهٔ اصلی کار می‌کنند)
۳. در برنامه روی 🔔 بزنید تا اعلان‌ها فعال شوند.

### دربارهٔ یادآوری وقتی برنامه بسته است
برنامه‌های وب محدودیت اجرا در پس‌زمینه دارند: اعلان‌ها وقتی برنامه باز یا در پس‌زمینهٔ اخیر است قطعاً می‌رسند و در مرورگرهایی که «Notification Triggers» را دارند از قبل زمان‌بندی می‌شوند.
برای اطمینان صددرصد، از دکمهٔ **«📆 افزودن به تقویم گوشی»** (در فرم هر کار یا در تنظیمات) استفاده کنید تا کار با هشدار در تقویم گوشی هم ثبت شود.

## اجرا روی کامپیوتر (برای توسعه)

```bash
npm start      # http://localhost:8080
npm test       # تست‌های تحلیل‌گر جمله و تقویم شمسی
```

## ساختار

```
index.html            صفحهٔ اصلی
css/style.css         ظاهر (راست‌به‌چپ، حالت تاریک خودکار)
js/parser.js          درک جملات فارسی (تاریخ، ساعت، تکرار، اولویت، یادآوری، مدت)
js/classifier.js      دسته‌بندی خودکار + یادگیری
js/analytics.js       تحلیل‌ها، پیشنهاد تمرکز و یادداشت‌های منشی
js/reminders.js       اعلان‌ها، گزارش صبحگاهی، خروجی تقویم (ics)
js/jalali.js          تبدیل تاریخ شمسی
js/store.js           ذخیره‌سازی محلی
js/contacts.js        مخاطبین و متن پیامک
js/native.js          ارتباط با اندروید (اعلان سیستمی و پیامک)
android/              پروژهٔ اندروید (Capacitor) + افزونهٔ ارسال پیامک زمان‌بندی‌شده
sw.js                 اجرای آفلاین و دکمه‌های اعلان
```
