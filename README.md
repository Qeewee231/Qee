# 📋 منشی من — دستیار هوشمند کارهای روزانه

یک برنامهٔ موبایل (PWA) فارسی که مثل یک منشی باتجربه کارهای روزانه‌تان را **ثبت، دسته‌بندی، تحلیل و یادآوری** می‌کند.
روی اندروید و آیفون کار می‌کند، بدون نیاز به اینترنت (بعد از اولین بار) و بدون سرور. همهٔ اطلاعات فقط روی گوشی خودتان می‌ماند.

## امکانات

| بخش | توضیح |
|---|---|
| 🗣 **ثبت با زبان طبیعی** | همان‌طور که حرف می‌زنید بنویسید یا با میکروفون بگویید: «فردا ساعت ۱۰ صبح جلسه با مدیر، فوری، ۳۰ دقیقه قبل یادم بنداز» |
| 📅 **تقویم شمسی** | «۱۲ آبان»، «۱۴۰۵/۹/۱»، «پنجشنبه»، «پس‌فردا»، «۳ روز دیگه»، «هفته بعد»، «امشب» |
| 🗂 **دسته‌بندی خودکار** | کاری، مالی، سلامت، خرید، خانواده، خانه و خودرو، آموزش، اداری، شخصی — و **یادگیری از اصلاحات شما** |
| 🔔 **یادآوری** | اعلان گوشی با دکمه‌های «انجام شد» و «۱۰ دقیقه بعد»، صدا و لرزش، گزارش صبحگاهی، افزودن به تقویم گوشی |
| 🔁 **کارهای تکراری** | هر روز، هر هفته، «هر دوشنبه»، هر ماه شمسی (مثلاً قسط)، هر سال |
| 🎯 **پیشنهاد تمرکز** | منشی بر اساس فوریت، اولویت و موعد می‌گوید «الان روی چه کاری تمرکز کنید» |
| 🧠 **یادداشت‌های منشی** | هشدار کارهای عقب‌افتاده، تداخل زمانی، حجم کار بیش از ساعات کاری، اهمال‌کاری، فراموش کردن سلامت و خانواده |
| 📊 **تحلیل عملکرد** | نرخ انجام، انجام به‌موقع، روزهای پیاپی، نمودار ۷ روز، تحلیل دسته‌ها، ساعت‌های پربازده، روزهای پرکار |
| 💾 **پشتیبان‌گیری** | خروجی/بازیابی فایل JSON برای انتقال به گوشی دیگر |

## نصب روی گوشی

۱. برنامه باید روی یک آدرس `https` باشد. ساده‌ترین راه **GitHub Pages** است:
   در گیت‌هاب: `Settings → Pages → Build and deployment → Deploy from a branch` و شاخهٔ برنامه و پوشهٔ `/ (root)` را انتخاب کنید.
   آدرس برنامه چیزی شبیه `https://<نام‌کاربری>.github.io/Qee/` خواهد شد.
۲. آدرس را روی گوشی باز کنید:
   - **اندروید (Chrome):** منو ⋮ ← «Add to Home screen / نصب برنامه»
   - **آیفون (Safari):** دکمهٔ اشتراک‌گذاری ← «Add to Home Screen» (اعلان‌ها در iOS 16.4 به بعد و فقط پس از افزودن به صفحهٔ اصلی کار می‌کنند)
۳. در برنامه روی 🔔 بزنید تا اعلان‌ها فعال شوند.

### دربارهٔ یادآوری وقتی برنامه بسته است
برنامه‌های وب محدودیت اجرا در پس‌زمینه دارند: اعلان‌ها وقتی برنامه باز یا در پس‌زمینهٔ اخیر است قطعاً می‌رسند و در مرورگرهایی که «Notification Triggers» را دارند از قبل زمان‌بندی می‌شوند.
برای اطمینان صددرصد، از دکمهٔ **«📆 افزودن به تقویم گوشی»** (در فرم هر کار یا در تنظیمات) استفاده کنید تا کار با هشدار در تقویم گوشی هم ثبت شود.

## اجرا روی کامپیوتر (برای توسعه)

```bash
npm start      # http://localhost:8080
npm test       # تست‌های تحلیل‌گر جمله و تقویم شمسی
```

## ساختار

```
index.html            صفحهٔ اصلی
css/style.css         ظاهر (راست‌به‌چپ، حالت تاریک خودکار)
js/parser.js          درک جملات فارسی (تاریخ، ساعت، تکرار، اولویت، یادآوری، مدت)
js/classifier.js      دسته‌بندی خودکار + یادگیری
js/analytics.js       تحلیل‌ها، پیشنهاد تمرکز و یادداشت‌های منشی
js/reminders.js       اعلان‌ها، گزارش صبحگاهی، خروجی تقویم (ics)
js/jalali.js          تبدیل تاریخ شمسی
js/store.js           ذخیره‌سازی محلی
sw.js                 اجرای آفلاین و دکمه‌های اعلان
```
